# Security

Found a way for an agent to get past the guard, such as reading a secret file, dumping the environment or running a blocked command? Please email **contact@rollcage.app** with the exact command or tool call, the agent and the version (`rollcage-guard --version`).

Bypasses that only work by having the agent write a script and then run it are a known limit (see "Limits" in the README), but reports that show a practical way to close them are still welcome.
